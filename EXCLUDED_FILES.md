# Excluded Files and Folders Report

This document details all categories and specific instances of files and directories excluded during the creation of the **Myintellibook Clean Transfer Package** from `D:\Projects\Myintellbook_live`.

Exclusions follow strict production safety guidelines to ensure no machine-specific, runtime, generated, sensitive, or redundant files are transferred to another environment or repository branch.

---

## 1. Summary of Exclusions

- **Total Excluded Files:** 77,898 files
- **Total Excluded Size:** ~463.99 MB (486,527,021 bytes)
- **Original Source Project Status:** **Untouched & Preserved** (Read-only export)

---

## 2. Exclusion Categories & Details

### Category 1: Version Control Internal Metadata
- **Path:** `.git/` (903 files, ~30.46 MB)
- **Reason:** Git repository internal database, pack files, commit history, branch pointers, and worktree tracking. When copying work into a newly cloned repository or branch, copying the old `.git` directory would corrupt or overwrite the destination's Git tracking.
- **Action Required on Destination:** Replaced by the destination repository's own `.git` management.

---

### Category 2: Backend Dependencies (Composer)
- **Path:** `MIB_backend/vendor/` (48,281 files, ~226.68 MB)
- **Reason:** Third-party PHP libraries installed by Composer. These must never be committed or transferred between environments because they are platform-dependent (PHP extensions, architecture, OS symlinks) and bloat the transfer archive.
- **Action Required on Destination:** Run `composer install --no-interaction` in `MIB_backend/` using the included `composer.json` and `composer.lock`.

---

### Category 3: Frontend Dependencies (Node.js / npm)
- **Path:** `MIB_frontend/node_modules/` (28,510 files, ~200.77 MB)
- **Reason:** Third-party Node modules installed by npm. These are OS-dependent (native binaries, platform-specific binaries for esbuild/rollup) and huge in volume.
- **Action Required on Destination:** Run `npm install` in `MIB_frontend/` using the included `package.json` and `package-lock.json`.

---

### Category 4: Frontend Distribution Build Output
- **Path:** `MIB_frontend/dist/` (133 files, ~3.30 MB)
- **Reason:** Compiled, minified JavaScript, CSS, and asset bundles generated by Vite (`npm run build`). These are runtime artifacts that should be rebuilt on the destination.
- **Action Required on Destination:** Run `npm run build` or `npm run dev` in `MIB_frontend/`.

---

### Category 5: Environment & Secrets Configuration
- **Path:** `MIB_backend/.env` (1 file, 2,327 bytes)
- **Reason:** Contains local database credentials (e.g., MySQL root passwords), application encryption keys (`APP_KEY`), mail credentials, Pusher/Reverb credentials, and host configs. Distributing `.env` poses severe security risks and can cause runtime connection failures on other machines with different credentials.
- **Safe Alternative Included:** `MIB_backend/.env.example` is fully preserved in the transfer package.
- **Action Required on Destination:** Duplicate `.env.example` to `.env` and run `php artisan key:generate`.

---

### Category 6: Laravel Framework Bootstrap Cache
- **Paths:**
  - `MIB_backend/bootstrap/cache/packages.php` (1 file, 1,909 bytes)
  - `MIB_backend/bootstrap/cache/services.php` (1 file, 23,013 bytes)
- **Reason:** Cache files generated during Laravel package auto-discovery containing hard-coded absolute filesystem paths to vendor packages on the current machine (`D:\Projects\...`).
- **Safe Baseline Preserved:** `MIB_backend/bootstrap/cache/.gitignore` is preserved to maintain the directory structure.
- **Action Required on Destination:** Laravel regenerates these automatically on first boot or when running `php artisan package:discover`.
